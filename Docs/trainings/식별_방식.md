# 식물 식별 방식

작성일: 2026-10-25

인수인계의 MVP 우선순위는 OpenAI Vision, 그다음 외부 식물 API, 그다음 사전 정의 DB다. 이 저장소는 1번과 3번을 한 경로에 넣었다.

## OpenAI Vision

`vision_service.py`가 이미지를 data URL로 붙여 `gpt-4o-mini`에 JSON 식별을 요청한다. 모델 이름은 `OPENAI_VISION_MODEL`로 바꾼다.

## 로컬 카탈로그

키가 없을 때도 화면 흐름이 끝나야 하므로 Pillow로 녹색 비율, 밝기, 채도, 대비, 따뜻한 색 정도를 계산하고 `plant_catalog.py`의 기준점과 거리를 비교한다. 신뢰도 문구에 이 사실을 적어 비전 모델 결과처럼 보이지 않게 했다.

## 가이드

`guide_service.py`는 같은 키 정책으로 한국어 가이드 JSON을 요청한다. 실패하면 카탈로그의 물주기·빛·온도·흙·비료·주의·계절 팁을 쓴다. 응답 `care_guide.source`가 `llm` 또는 `catalog`다.
