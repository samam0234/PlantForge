# 실행 가이드

작성일: 2026-10-25

세 프로세스를 각각 켠다. 순서는 Flask, Express, Svelte.

## Flask (5000)

```bash
cd ai-server
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python run.py
```

`python app/main.py`는 패키지 상대 import 때문에 쓰지 않는다. 진입점은 `run.py`다.

## Express (3000)

```bash
cd backend
npm install
copy .env.example .env
npm run dev
```

## Svelte (5173)

```bash
cd frontend
npm install
npm run dev
```

브라우저에서 샘플 버튼을 누르고 식별을 실행하면 몬스테라, 스킨답서스, 에케베리아 예시 이미지가 파이프라인을 탄다. 직접 찍은 사진도 같은 버튼으로 분석한다.

## API 키

`ai-server/.env`의 `OPENAI_API_KEY`가 비어 있으면 로컬 카탈로그만 사용한다. 키를 넣으면 식별은 Vision, 가이드는 채팅 모델이 맡고, 호출이 실패하면 카탈로그로 돌아간다. `AI_PROVIDER=local`이면 키가 있어도 카탈로그만 쓴다.
