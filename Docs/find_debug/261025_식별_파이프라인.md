# 식별 파이프라인 디버그 메모

- **날짜**: 2026-10-25
- **증상 후보**: 화면은 뜨는데 식별이 실패하거나, 항상 같은 종만 나옴
- **확인 순서**:
  1. `http://localhost:5000/health`의 `provider.active`가 `openai-vision`인지 `local-catalog`인지 본다.
  2. `http://localhost:3000/health`의 `aiServer.status`가 `offline`이면 Express가 Flask에 닿지 못한 것이다. `AI_SERVER_URL`과 5000 포트 리슨을 확인한다.
  3. 브라우저 토스트 문구가 Express `message`와 같은지 본다. 10MB 초과와 JPG/PNG/WEBP 이외 형식은 400이다.
  4. `backend/uploads/`에 파일이 생겼는지, `identifications.raw_result`에 Flask JSON이 남았는지 확인한다.
- **로컬 카탈로그의 한계**: 색 분포로 실내 식물 8종 중 가까운 항목을 고른다. 예시 이미지는 그 기준점에 맞춰 두었고, 현장 사진은 OpenAI Vision이 있을 때 더 정확하다.
- **한글이 콘솔에서 깨져 보일 때**: SQLite와 JSON 응답은 UTF-8이다. Windows 콘솔 코드 페이지와 별개로 DB 값을 확인한다.
