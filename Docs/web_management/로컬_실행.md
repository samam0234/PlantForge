# 웹 관리 메모

작성일: 2026-10-25

현재 배포 대상은 로컬 개발 서버다. 포트는 프론트 5173, Express 3000, Flask 5000으로 고정한다.

## 운영 시 지킬 것

- `.env`와 `plantforge.db`, `backend/uploads/`는 커밋하지 않는다
- API 키는 `ai-server/.env`에만 둔다
- 식별 실패를 숨기는 고정 목업 응답은 쓰지 않는다. 사용자는 토스트로 원인을 본다
- `docker-compose.yml`은 선택 구성이다. 이미지 빌드용 Dockerfile은 MVP 범위에 넣지 않았고, 실행 기준은 각 디렉터리의 README다

## 이후 배포 때 바꿀 자리

- 업로드 경로를 객체 저장소로 옮길 때 Express `imageUrl`과 `plants.image_path`만 맞추면 화면의 `resolveImageUrl`은 상대 경로와 절대 URL을 모두 받는다
- 프록시 뒤에서 프론트를 띄우면 `VITE_API_URL`과 `CORS_ORIGIN`을 그 주소로 바꾼다
